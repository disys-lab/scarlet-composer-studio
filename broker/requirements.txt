# connector classes (mssql/postgres/mysql/pi/influx/redis) and their own
# drivers, extracted into their own package so both this broker and
# scarlet-agentic-harness's local-config mode can import the same classes

# packages (setup.py / setup_composer.py) - not a name pip can resolve
# via a plain requirements.txt line.

# versions with no installable wheel for a modern Python).
